# مدار للإرشاد الجامعي

[افتح مدار](https://salahassi.github.io/madar-academic-advisor/) · [جرّب المرشد الصوتي](https://salahassi.github.io/madar-academic-advisor/#voice)

تطبيق عربي يساعد الطالب على اختيار المقررات وبناء جدول يناسب وقتَه وفهم أثر التأجيل أو تغيير العبء الدراسي على خطته ومعدّله. اختر «تجربة بداية الدراسة» (DEMO-NEW) أو «تجربة المستوى الخامس» (DEMO-05) لاستكشاف مسارين مختلفين. تُولّد كل تجربة مثالًا دراسيًا من المقررات الافتراضية، وتُحفظ تغييرات التسجيل في متصفحك.

ينشر GitHub Pages التطبيق من مجلد `docs/` على فرع `main`. للتشغيل محليًا، شغّل `python -m http.server 8000 --directory docs` من جذر المستودع، ثم افتح `http://localhost:8000`.

يضم مجلد `model/` أمثلة التدريب والاختبار ومصدر النموذج الذي يصنّف الأسئلة والاهتمامات. ترافق ملفات التراخيص النماذج والمكتبات والخطوط داخل `docs/assets/`.
